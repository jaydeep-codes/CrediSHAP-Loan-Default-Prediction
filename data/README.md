# Data Directory

The dataset (`dataset.csv`) is **not included** in this repository due to its size (~27 MB).

## Download the Dataset

Download the **Loan Default Dataset** from Kaggle:

👉 [Loan Default Prediction Dataset on Kaggle](https://www.kaggle.com/datasets/nikhil1e9/loan-default)

After downloading, place the file here:

```
data/
└── dataset.csv
```
